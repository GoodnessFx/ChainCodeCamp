## Value moves in exactly three places

Every token on Ethereum is just numbers in a contract's storage plus two events the world agrees to watch. There is no coins folder. Open any ERC20 and find the three things that move:

```solidity
mapping(address => uint256) private s_balances;
mapping(address => mapping(address => uint256)) private s_allowances;
uint256 private s_totalSupply;
```

The move itself is boring on purpose:

```solidity
function transfer(address to, uint256 amount) external returns (bool) {
    s_balances[msg.sender] -= amount;
    s_balances[to] += amount;
    emit Transfer(msg.sender, to, amount);
    return true;
}
```

Three writes on success: two balances, one log. Everything an attacker can do in this function is some path through those three writes. That is the whole audit in miniature: list the writes, then ask what happens when `amount` is zero, huge, or sent to yourself.

## Slots are addresses you can compute

The EVM has 2^256 storage slots. Fixed variables take slots in declaration order starting at 0. A mapping's entries scatter by hash: for `balances` at slot 0, Alice's balance sits at `keccak256(abi.encode(Alice, uint256(0)))`.

<SpotIt>

In any unknown ERC20-style codebase, read in this order:

```bash
grep -rn "function transfer\|function transferFrom\|function approve" src/
```

Then open each hit and list its state writes. The bug is always a write the author
forgot was reachable: missing allowance decrement, a self-transfer path, or an
event that lies about what moved.

</SpotIt>

<FixIt>

When you find a wrong write, the fix is mechanical: update every balance and
allowance before any external call, emit the event last, and add the exact test
that failed before. Re-run to prove it:

```bash
forge test -vv
```

Green means the write order is now safe, not that the code is clever.

</FixIt>

## Real-world case: a slow leak, not a drain

In 2021 Compound's Comptroller dripped COMP rewards at the wrong rate after an
upgrade. No one stole anything; the math itself overpaid until governance paused
it, with around $80M briefly at risk. Write-order bugs do not always look like a
hack. Sometimes they look like generosity.

Read the post-mortem: https://compound.finance/governance/proposals/64
